# axi-pcie-core

[DOE Code](https://www.osti.gov/doecode/biblio/75521)

``axi-pcie-core`` is an AXI-Lite/AXI-Stream interconnect and DMA infrastructure
library for SLAC firmware projects, used as a git submodule by applications
targeting PCIe carrier boards.

See the documentation at https://slaclab.github.io/axi-pcie-core/.
